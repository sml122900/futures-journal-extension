### 디버깅 — 주입 문제
- 비트겟 URL 로케일 prefix 확인: `/asia/futures/` → manifest matches 패턴 추가
- `attachInterceptor` + MutationObserver → `document.addEventListener('click', ..., true)` 방식으로 전환
- `handleEntryClick`이 async 후 `preventDefault` 호출하는 버그 수정 (동기/비동기 분리)

### 디버깅 — Bitget DOM 셀렉터 확인
- 진입 버튼: `button[role="buyer"]` / `button[role="seller"]`
- 수량 입력: `input[data-testid="FutureTradeLimitOrderAmountInput"]`, `name="op-amount"`
- `getSize()`: `data-testid*="OrderAmountInput"` 부분 일치로 시장가/지정가 모두 대응

### 디버깅 — CORS
- Content script fetch → `www.bitget.com` origin → 서버 차단
- 해결: `background.js` service worker 경유 (`chrome-extension://` origin 사용)
- `chrome.runtime.onMessage` → `_doFetch` → `sendResponse` 패턴
- `api-client.js` 전체를 `chrome.runtime.sendMessage` 기반으로 교체

### 디버깅 — 타임아웃
- `API_TIMEOUT` 1,000ms → 5,000ms, `EMERGENCY_TIMEOUT` 8,000ms 분리
- `emergency-check` 서버 타이밍 로그 추가 (auth / setting / detectEmergency / session create)
- Vercel cold start 대응 warm-up ping (`ApiClient.warmUp()`) 추가

### 디버깅 — UserBaseline 0건
- `EmergencySetting.l1=l2=l3=1` (비정상) → 1.5 / 2.0 / 5.0 수정
- `baseline-calculator.ts` Bitget API 필드명 불일치 수정:
  - `marginSize` (없음) → `openTotalPos × openAvgPrice` (USDT notional)
  - `cTime` (없음) → `ctime` (소문자, 오픈 시각)
  - `closeTime` (없음) → `utime` (소문자, 클로즈 시각)
- 90개 포지션으로 baseline 생성 성공
